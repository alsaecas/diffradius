# DiffRadius hackathon video

This directory contains the complete Remotion source and final 4:42 submission video.

## Render

Requirements: Node.js, npm, FFmpeg, and (only when regenerating missing narration clips) macOS `say` with the Samantha voice.

```bash
cd video
npm install
npm run render
```

`npm run render` first verifies and syncs `../evidence/results/comparison.json`, regenerates the SRT, ensures local audio exists, and renders H.264/AAC to:

```text
out/diffradius-hackathon-final.mp4
```

Narration clips and the procedural ambient bed are committed, so normal rendering does not require `say` and makes no network or paid TTS call. If an audio file is deliberately removed, `npm run audio` regenerates it locally.

## Source of truth

- `src/data/evidence.json` is generated by `scripts/sync-evidence.mjs` from the committed frozen result.
- The sync script refuses an unexpected fingerprint or case count.
- `src/data/content.json` is the shared timing source for narration clips, embedded captions, and the generated SRT.
- Case 15 visuals reproduce only actions and excerpts in the committed trajectory.

## Useful commands

```bash
npm run sync
npm run captions
npm run audio
npx tsc --noEmit
npx remotion still src/index.ts DiffRadiusFinal out/check.png --frame=5550
```

No production DiffRadius code, benchmark output, scoring rule, or frozen evidence file is modified by the video build.
