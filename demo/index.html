THE BOTTLENECK

A diff is compact.
Its consequences are not.

Senior reviewers routinely have to leave the changed lines and inspect callers, consumers, persisted data, auth boundaries, caches, retries, configuration and async lifecycles.

Single-pass AI review often stops once the local patch looks plausible. DiffRadius makes leaving the diff an explicit part of the workflow.

PURPOSEFUL ORCHESTRATION

Each stage has one job.

More agents are not automatically better. The benchmark contains a full ablation matrix so each extra stage has to earn its latency and cost.

  • Release decision

REPRODUCIBLE FROM CLEAN
Clone. Validate. Evaluate.
The deterministic integrity checks need no API key. A live model run is one command after setting the key in your shell.
Full reproduction guide ↗
terminal
$ git clone https://github.com/alsaecas/diffradius.git
$ cd diffradius
$ python -m venv .venv
$ source .venv/bin/activate
$ pip install -e '.[dev]'

# No API key required
$ pytest
$ python scripts/validate_benchmark.py

# Full baseline → ablation → final matrix
$ export OPENAI_API_KEY='...'
$ diffradius evaluate --mode all
